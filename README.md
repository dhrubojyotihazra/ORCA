# ORCA: Marine EcOsystem Reasoning with Collaborative Agents

A multi-agent simulation framework for monitoring, analyzing, and mitigating environmental threats in marine ecosystems.

## Overview

ORCA simulates a collaborative agent framework to maintain ecological health:
1. **Sensor Agent**: Gathers real-time environmental telemetry (Temperature, pH, and Dissolved Oxygen).
2. **Analysis Agent**: Evaluates telemetry for anomalies (e.g., marine heatwaves, ocean acidification, hypoxia) and alerts the system.
3. **Action Agent**: Proposes target conservation strategies to mitigate detected threats.

## Getting Started

To run the simulation, run:
```bash
python orca_simulation.py
```
