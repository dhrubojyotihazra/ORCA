# ORCA Technical Stack

- **Orchestration**: LangGraph (multi-agent orchestration)
- **Backend**: FastAPI
- **Database/Persistence**: Supabase
- **Frontend**: Next.js + Leaflet/Mapbox
- **Data Integrations**:
  - MOSDAC (SST, Chlorophyll, Ocean Current)
  - INCOIS ERDDAP/WebGIS (PFZ, Advisories, Alerts)
  - Public GIS Layers (Boundaries, Protected Areas)
